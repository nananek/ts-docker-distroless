# Syscalls removed from every SCMP_ACT_ALLOW rule in seccomp/tailscale.json.
#
# Keep this list limited to syscalls that tailscaled does not need in this
# image. The setreuid/setresuid family is defense in depth; the SSH-critical
# setgroups/setuid/setgid are blocked by sandbox-exec, not by this profile
# (see the note in the first section).
#
# One name per line. Lines starting with # and blank lines are ignored.

# --- Tailscale SSH privilege drop -------------------------------------------
# ssh/tailssh/incubator.go: doDropPrivileges() calls setgroups()
# unconditionally, then setgid()/setuid() when the target uid/gid differs.
# Root sessions call setgroups() too, so blocking it disables every session.
#
# setgroups/setgid/setuid are deliberately NOT in this file. runc installs a
# custom seccomp profile before setupUser() when no-new-privileges is false, so
# removing these three from the allowlist makes the container fail at startup
# with EPERM. The image's sandbox-exec installs the same block after runc has
# finished, so Tailscale SSH is still disabled.
#
# The remaining set*id calls are not used by runc's setupUser().
#
# If you intentionally add setgroups/setgid/setuid back, update
# scripts/check-seccomp.sh too and always run with
# --security-opt no-new-privileges:true.
setreuid
setreuid32
setregid
setregid32
setresuid
setresuid32
setresgid
setresgid32
setfsuid
setfsuid32
setfsgid
setfsgid32
